# Blood Bank Website

## Overview

This project is a full-stack blood bank management system designed to streamline the process of blood donation and management. It includes role-specific functionalities for donors, hospitals, organizations, and admins, and features dashboards for tracking blood type inflows and outflows as well as recent transactions.

## Features

- **Role Management**:
  - **Donors**: Register and view their donation history.
  - **Hospitals**: Manage blood requests and view blood type availability.
  - **Organizations**: Coordinate blood donation drives and manage donor information.
  - **Admins**: Oversee the entire system, including user management and transaction tracking.

- **Dashboards**:
  - Track blood type inflows and outflows.
  - View recent transactions to monitor activity.

- **Role-Specific Functionalities**:
  - Each role has tailored features and access permissions to ensure efficient operation.

- **Secure Authentication**:
  - Utilized JWT for secure user authentication, protecting sensitive data.

- **State Management**:
  - Implemented Redux for effective state management across the application.
